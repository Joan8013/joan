## 1. 方案摘要

拓展平台新增建单接口 `POST /system/dispute/parkingOrder/create`（路径待定）。处理链路：
参数校验 → 幂等校验（客户号+账单号+24h）→ 建单（借鉴投诉工单编号规则）+ 字段映射 → 按停车场编号推送商户后台 → 车场上传图片回调 → 更新工单状态=已完成 + 回传（图片地址、上传时间）+ 触发短信。

## 5. 接口契约（详细，⚠️ 鉴权/协议部分为假设，待 HOLD-002/003 确认）

### 5.1 建单接口（入：互联网系统 → 拓展平台）

- Method/Path（建议）：`POST /system/dispute/parkingOrder/create`
- 鉴权：待确认（HOLD-002，建议复用现有系统间 Feign 鉴权或签名）
- 请求体：

| 字段 | 名称 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| customerNo | 客户号 | String | 是 | 幂等键之一 |
| userName | 用户名称 | String | 是 |  |
| mobile | 手机号 | String | 是 | 短信通知用 |
| plateNo | 车牌号 | String | 是 |  |
| plateColor | 车牌颜色 | String | 是 |  |
| etcCardNo | ETC 卡号 | String | 是 |  |
| parkingLotNo | 停车场编号 | String | 是 | 推送匹配键 |
| parkingLotName | 停车场名称 | String | 是 |  |
| entryTime | 入场时间 | DateTime | 是 |  |
| exitTime | 出场时间 | DateTime | 是 |  |
| billAmount | 账单金额 | BigDecimal | 是 | 只读透传，不参与计算 |
| tradeTime | 交易时间 | DateTime | 是 |  |
| billNo | 停车账单号/交易流水号 | String | 是 | 幂等键之一（⚠️ 原始材料未显式给出账单唯一标识，待确认 HOLD-006） |
| disputeTime | 质疑时间 | DateTime | 是 |  |

- 响应体：`{ code, msg, data: { orderNo, status } }`
  - 成功：`code=200`，返回 `orderNo`（工单编号）、`status=待处理`
  - 重复质疑：`code=DUPLICATE`（业务码），不新增工单
  - 参数缺失：`code=PARAM_MISSING`

## 6. 数据库表设计（DDL 建议，⚠️ 复用 vs 新建待确认 RISK-004）

方案：新建工单表 + 图片子表（若最终决定复用投诉工单表，则改为在其上加 `source_type` 与关联图片）。

```sql
-- 停车账单质疑工单
CREATE TABLE dispute_parking_order (
    id             BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_no       VARCHAR(64)  NOT NULL COMMENT '工单编号(借鉴投诉工单编号规则)',
    source_type    VARCHAR(32)  NOT NULL DEFAULT 'PARKING_BILL_DISPUTE' COMMENT '来源类型',
    customer_no    VARCHAR(64)  NOT NULL COMMENT '客户号',
    user_name      VARCHAR(64),
    mobile         VARCHAR(20),
    plate_no       VARCHAR(20)  NOT NULL,
    plate_color    VARCHAR(16),
    etc_card_no    VARCHAR(32),
    parking_lot_no VARCHAR(64)  NOT NULL COMMENT '停车场编号(推送匹配键)',
    parking_lot_name VARCHAR(128),
    entry_time     DATETIME,
    exit_time      DATETIME,
    bill_amount    DECIMAL(18,2) COMMENT '账单金额,只读透传',
    trade_time     DATETIME,
    bill_no        VARCHAR(64)  NOT NULL COMMENT '停车账单号/流水号',
    dispute_time   DATETIME,
    status         VARCHAR(16)  NOT NULL DEFAULT '待处理' COMMENT '待处理/处理中/已完成',
    image_upload_time DATETIME,
    create_time    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_order_no (order_no),
    UNIQUE KEY uk_customer_bill (customer_no, bill_no) COMMENT '支撑24h幂等(配合应用层校验)',
    KEY idx_parking_lot (parking_lot_no),
    KEY idx_plate (plate_no)
);

-- 工单图片佐证(≤3)
CREATE TABLE dispute_parking_order_image (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_no    VARCHAR(64)  NOT NULL,
    image_url   VARCHAR(512) NOT NULL,
    upload_time DATETIME     NOT NULL,
    operator    VARCHAR(64),
    KEY idx_order_no (order_no)
);
```

> 幂等说明（DEC-001）：`uk_customer_bill` 保证同一(客户号,账单号)只落一条；应用层再做 24h 预校验给出友好 DUPLICATE 返回。若允许历史(>24h)再次质疑，则唯一键需改为带时间窗的软校验，此点待 HOLD-006 一并确认。
