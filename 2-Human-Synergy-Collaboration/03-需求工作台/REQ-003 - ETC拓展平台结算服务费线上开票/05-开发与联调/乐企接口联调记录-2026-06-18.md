## 4. 关键问题与修正

| 编号 | 问题 | 处理结论 |
| --- | --- | --- |
| ISSUE-001 | 普通 HTTPS POST 无法满足乐企双向证书要求 | 改为加载 PFX 证书并使用 `HttpsURLConnection` 发起双向 HTTPS 请求 |
| ISSUE-002 | DTO 驼峰字段无法被乐企识别 | 对乐企 DTO 增加 `@JsonProperty`，输出 `FPQQLSH`、`XSF_NSRSBH` 等大写字段 |
| ISSUE-003 | 响应不是扁平 `CODE/MESSAGE/DATA`，而是外层 `interface` 信封 | 先解析外层 `interface.data.content`，再 Base64 解码业务响应 |
| ISSUE-004 | 乐企金额字段按 JSON number 传递时被判定必填缺失 | 对金额、数量、单价、税率等 BigDecimal 字段使用字符串序列化 |
| ISSUE-005 | 外部接口测试不能随普通构建自动执行 | 集成测试默认跳过，仅在 `LEQ_INTEGRATION_TEST=true` 时执行 |

## 7. 安全要求

1. 代码、SQL、文档中不得硬编码 APPID、AES 密钥、证书密码、token。
2. 日志中不得打印密钥、证书密码、完整敏感配置。
3. 真实外部接口测试默认关闭，必须显式开启。
4. 列表查询禁止返回 `request_payload`、`item_detail_payload` 等大字段。
5. SQL 查询必须使用 MyBatis 参数绑定，禁止拼接用户输入。
