## 原始需求：平台结算服务费开票功能

### 一、业务背景

我们是一家ETC停车费结算平台，为停车场提供停车费代扣结算服务，并向停车场收取**结算服务费**。停车场需要我们就这笔服务费开具发票。

### 二、核心需求

我们需要在系统内提供一个**线上开票功能**，让停车场（商户）可以自主申请开票，平台审核后开具发票。

### 三、业务角色

- **销售方（开票方）**：我们平台（发票上的销售方名称、税号由财务统一配置，固定不变）
- **购买方（收票方）**：停车场/商户（发票抬头为商户的企业名称，税号为商户的纳税人识别号）

### 四、核心流程

1. 商户在系统中选择已结算的对账单，发起开票申请
2. 系统自动带入商户信息作为购买方信息（名称、税号不可修改）
3. 同一张对账单可拆分为多张发票，但各张发票的价税合计之和必须等于对账单总金额
4. 财务审核通过后，系统调用乐企接口开票
5. 开票成功回写发票号码、代码、开票日期、下载地址等信息
6. 商户可在列表中查看、下载已开发票
7. 若开票失败（如网络超时），支持重新申请

### 五、页面需要展示的信息

需要一个发票列表页面，展示每张发票的以下信息：

- 服务汇总编号（关联对账单）
- 业务性质（如结算服务费）
- 发票类型（数电专票/数电普票，由商户选择）
- 发票抬头（商户企业名称）
- 购买方纳税人识别号（商户税号）
- 发票代码（开票成功后回写）
- 发票号码（开票成功后回写）
- 价税合计
- 不含税金额（系统自动计算：价税合计 ÷ 1.06）
- 税额（系统自动计算：价税合计 - 不含税金额）
- 开票时间
- 开票状态（待开票/开票中/已开票/开票失败）
- 失败原因（仅失败时展示）

### 六、操作需求

- 已开票：可下载PDF发票
- 开票失败（网络超时等）：可点击重新开票
- 同一张发票最多允许重试3次

### 七、筛选需求

页面支持按以下条件筛选：
- 商户名称
- 发票号码
- 开票日期区间
- 开票状态

### 八、权限需求

- 商户端：只看到自己名下的发票
- 平台端（财务/运营）：可看到所有商户的发票

### 九、特殊要求

- 发票类型由商户自行选择（专票或普票）
- 若商户选择专票，需为一般纳税人（由运营后台标记）

### 十、数电票接口字段映射（新增，基于2025-06-17讨论结果）

以下为调用乐企数电票接口时，各字段的传参来源及规则说明：

| **接口字段** | **拓展传参** | **传参规则说明** |
|--------------|---------------|------------------|
| **购买方名称** | 运营后台的商户信息中的企业名称 | 自动带入商户信息对应的内容，不可修改 |
| **购买方纳税人识别号** | 运营后台的商户信息中的开票信息里的纳税人识别号 | 自动带入商户信息对应的内容，不可修改 |
| **销售方名称** | 广东联合电子服务股份有限公司 | 统一配置，固定传参 |
| **销售方纳税人识别号** | 914400007408467653 | 统一配置，固定传参 |
| **价税合计** | 商户同一张对账单下，拆分出来单张发票金额（对应对账单中「开票信息N」的金额） | 所有「开票信息N」的金额加起来，必须等于对账单的总金额 |
| **合计金额（不含税）** | 系统按「价税合计 ÷ 1.06税率」自动计算 | 当一张对账单拆分为多张发票开具时，每张发票先按「价税合计 ÷ 1.06」计算不含税金额，再用「价税合计 - 不含税金额」计算税额 |
| **合计税额** | 系统按「价税合计 - 合计金额」自动计算 | 按财务指定公式计算 |
| **税率** | 固定 0.06 | 统一传参0.06，不可修改 |
| **发票类型** | 商户选择的票种（专票 / 普票） | 直接映射商户信息中开票信息选择的发票类型 |
| **开票人** | 梁寅庆 | 按财务要求，开票人显示业务侧负责人 |
| **项目名称** | 其他生产生活服务 | 统一配置，固定传参 |
| **规格型号** | \* | 具体见财务提供的发票样例 |
| **单位** | 项 | 统一配置，固定传参 |
| **数量** | 1 | 统一配置，固定传参 |
| **单价** | 3581.103773584905（示例值） | 按财务公式计算，实际以系统逻辑为准 |
| **税收分类编码** | 3079900000000000000 | 统一配置，固定传参 |

> **补充说明**：  
> - 旧开票功能与新功能将并行一段时间，为避免重复开票，新功能上线后由业务确认一个时间节点（以划账时间为准），节点视投产情况而定。  
> - 不支持发票红冲，若商户需红冲，需走人工流程，由商户申请后财务处理。  
> - 开票存在部分成功/失败可能，失败时可重新触发开票接口。
