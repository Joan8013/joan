### 5.5 项目明细字段

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `project_name` | varchar(128) | 是 | 项目名称，固定服务费，对应乐企 `XMMC` |
| `specification_model` | varchar(128) | 是 | 规格型号，固定 `*`，对应乐企 `GGXH` |
| `xmje_amount` | decimal(18,2) | 是 | 项目金额/不含税金额，单位元，保留 2 位小数，对应乐企 `XMJE` |
| `unit_name` | varchar(32) | 是 | 单位，固定项，对应乐企 `DW` |
| `quantity` | varchar(2) | 是 | 数量，固定字符串 `"1"`，对应乐企 `XMSL` |
| `unit_price` | varchar(15) | 是 | 单价 XMDJ：`JSHJ÷1.06` 格式化，总长 ≤15、最多 13 位小数 |
| `tax_class_code` | varchar(32) | 是 | 税收分类编码，固定 `3079900000000000000` |

设计结论：

1. `unit_price` 按 SQL 设计为 `varchar(15)`，不再使用 decimal。
2. 数据库存储值与乐企报文字段一致，避免 BigDecimal 精度和格式化差异。
3. 当前数量固定为 `"1"`，**XMDJ 与 2 位 HJJE 分离**：XMDJ 从 JSHJ 高精度拆税。
4. `xmje_amount` 为项目明细层不含税金额，建表语句只定义字段，不表达它与 `hjje_amount` 的等式关系。
5. 金额汇总关系由代码计算保证：`hjje_amount = N × xmje_amount`，其中 `N` 为本张发票的项目明细数量；数据库不体现该业务关系。

## 8. 金额计算规则

单张发票（**不调平**）：

```text
JSHJ = 上游传入价税合计，元，2 位小数
HJJE = round(JSHJ ÷ 1.06, 2)
HJSE = JSHJ - HJJE
XMSL = "1"
XMJE = HJJE
XMDJ = format(JSHJ ÷ 1.06)   /* 乐企精度，非 HJJE 字符串 */
```

多张发票：

```text
各行独立按上式计算 HJJE/HJSE/XMDJ
仅校验 sum(JSHJ_i) = 申请可开票金额
不做最后一张 HJJE/HJSE 尾差调平
```

**invoice 表**：已删除 `has_tail_diff`、`tail_diff_amount`（迁移脚本 `recon_bill_invoice_drop_tail_diff_columns.sql`）。  
**detail 表**：两字段保留但固定写 `0`，仅兼容历史 DDL。

## 9. 查询性能约束

1. 列表查询严禁 `SELECT *`。
2. 列表接口严禁返回 `request_payload`。
3. 列表接口严禁返回 `item_detail_payload`。
4. 查询必须使用参数绑定，禁止拼接用户输入。
5. 商户端列表优先使用 `idx_merchant_status`、`idx_recon_bill_id`、`idx_invoice_no`。

## 10. 代码控制的业务规则

| 规则 | 控制位置 |
| --- | --- |
| 汇总周期快照 | `ReconBillInvoiceBzUtils.buildSnapshotAtCreate` @ 汇总创建 |
| apply/invoice 周期拷贝 | `copyToApply` / `createInvoicesFromApply`；禁止 `resolve` 重算 |
| 乐企 BZ 格式 | `buildInvoiceBz`；见 `汇总周期与乐企BZ设计-v1.md` |
| 同一申请同一 `split_seq` 不可重复开票 | `uk_apply_split_seq` + Service |
| 同一 `detail_id` 不可重复生成 invoice | `uk_detail_id` |
| 一张申请生成几张发票 | 申请明细条数 ≤ `invoice_limit`；`createInvoicesFromApply` 1:1 |
| apply `issue_status` 汇总 | `syncApplyIssueStatus`（读 invoice 状态，不写 success_count） |
| 审核人/意见 | `insertInvoiceApplyAuditLog`，不写 apply 快照列 |
| 拆票金额 | 各行独立拆税；**仅校验 JSHJ 合计** |
| `fpqqlsh` 幂等 | LHDF 稳定生成 + `uk_fpqqlsh`；重试复用原号 |
| 失败重试资格 | `retryIssue`：`invoice_status` 1 或 3，且 `retry_count < 3` |
