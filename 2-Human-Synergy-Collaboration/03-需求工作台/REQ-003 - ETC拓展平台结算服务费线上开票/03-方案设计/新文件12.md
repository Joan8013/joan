## 一、前提条件

- 对账单总价税合计：`TOTAL`（元，2位小数）
- 拆分后各张发票的价税合计：`SPLIT₁`、`SPLIT₂`、...、`SPLITₙ`
- 约束：`ΣSPLIT = TOTAL`（上游已保证）
- 每张发票的价税合计 `SPLITᵢ` 是固定值，**永远不变**，调平只调最后一张的不含税和税额


## 二、计算步骤

### 第1步：计算整开一张的基准值

> 不含税基准 = `TOTAL ÷ 1.06`，四舍五入到2位小数
>
> 税额基准 = `TOTAL - 不含税基准`

### 第2步：处理前 N-1 张发票（正常除法 + 四舍五入）

对 `i = 1` 到 `N-1`：

> 不含税ᵢ = `SPLITᵢ ÷ 1.06`，四舍五入到2位小数
>
> 税额ᵢ = `SPLITᵢ - 不含税ᵢ`

### 第3步：计算最后一张发票（第 N 张）—— 调平逻辑

> 价税合计ₙ = `SPLITₙ`（**保持不变**，不做任何调整）
>
> 不含税ₙ = `不含税基准 - Σ(不含税₁ + ... + 不含税ₙ₋₁)`
>
> 税额ₙ = `价税合计ₙ - 不含税ₙ`

### 第4步：校验（系统自动执行，失败则拒绝）

1. Σ(各张价税合计) = TOTAL ✅
2. Σ(各张不含税) = 不含税基准 ✅
3. Σ(各张税额) = 税额基准 ✅
4. 每张票内：价税合计 = 不含税 + 税额 ✅


## 三、具体例子

对账单总额 **100.00 元**，拆成 **3 张**发票：33.33、33.33、33.34。

**第1步：整开基准**

> 不含税基准 = 100.00 ÷ 1.06 = 94.3396 → 四舍五入 = **94.34**
>
> 税额基准 = 100.00 - 94.34 = **5.66**

**第2步：前 N-1 张（第1张、第2张）正常计算**

| 发票 | 价税合计 | 不含税计算 | 不含税（2位） | 税额 |
| :--- | :--- | :--- | :--- | :--- |
| ① | 33.33 | 33.33 ÷ 1.06 = 31.443396 | **31.44** | 33.33 - 31.44 = **1.89** |
| ② | 33.33 | 33.33 ÷ 1.06 = 31.443396 | **31.44** | 33.33 - 31.44 = **1.89** |

前两张合计：价税 66.66，不含税 62.88，税额 3.78

**第3步：最后一张（第3张）调平**

| 字段 | 计算 | 结果 |
| :--- | :--- | :--- |
| 价税合计₃ | 保持不变 | **33.34** |
| 不含税₃ | 94.34 - 62.88 | **31.46** |
| 税额₃ | 33.34 - 31.46 | **1.88** |

**第4步：校验**

| 校验项 | 合计值 | 预期值 | 结果 |
| :--- | :--- | :--- | :--- |
| 价税合计 | 33.33 + 33.33 + 33.34 = 100.00 | 100.00 | ✅ |
| 不含税合计 | 31.44 + 31.44 + 31.46 = **94.34** | 94.34 | ✅ |
| 税额合计 | 1.89 + 1.89 + 1.88 = **5.66** | 5.66 | ✅ |

## 四、开发编码规则（伪代码）

```java
// 入参：对账单总价税合计 total，拆分金额列表 splitList（已保证相加=total）
public List<InvoiceAmount> calculateWithTailAdjustment(BigDecimal total, List<BigDecimal> splitList) {
    int n = splitList.size();
    List<InvoiceAmount> result = new ArrayList<>();
    
    // 第1步：整开基准
    BigDecimal baseExclTax = divideAndRound(total, new BigDecimal("1.06"), 2); // 94.34
    BigDecimal baseTax = total.subtract(baseExclTax); // 5.66
    
    // 第2步：前 N-1 张正常计算
    BigDecimal sumExclTax = BigDecimal.ZERO;
    for (int i = 0; i < n - 1; i++) {
        BigDecimal exclTax = divideAndRound(splitList.get(i), new BigDecimal("1.06"), 2);
        BigDecimal tax = splitList.get(i).subtract(exclTax);
        result.add(new InvoiceAmount(splitList.get(i), exclTax, tax));
        sumExclTax = sumExclTax.add(exclTax);
    }
    
    // 第3步：最后一张调平
    BigDecimal lastSplit = splitList.get(n - 1);
    BigDecimal lastExclTax = baseExclTax.subtract(sumExclTax);
    BigDecimal lastTax = lastSplit.subtract(lastExclTax);
    result.add(new InvoiceAmount(lastSplit, lastExclTax, lastTax));
    
    // 第4步：校验（略）
    return result;
}
```


## 五、边界情况处理

| 情况 | 处理方式 |
| :--- | :--- |
| 拆成1张（不拆票） | 按整开一张计算，不触发尾差调平逻辑 |
| 拆成2张 | 第1张正常计算，第2张为最后一张，承担尾差 |
| `lastExclTax` 出现负数 | 属于数据异常（前几张不含税和已超过基准），**拒绝请求并告警**，不强行调平 |
