# 03-方案设计

存放业务方案、技术方案、数据方案和风险处理方案。

本阶段输出应至少回答：

1. 准备怎么实现。
2. 哪些方案被排除。
3. 高风险口径是否已有人工确认。
4. 方案如何验证。

## 版本管理规则（避免"很多版看不到总览"）

1. **单一现行文档**：方案设计只保留一个 `方案设计.md`，永远代表最新确定的设计。
2. **禁止**新建 `方案设计-v7.md` 这类文件名版本；修改直接更新现行文档，并在其"变更记录"追加一行。
3. 版本演进依赖 **git 历史**；历史迭代稿统一放 `历史版本/` 仅供追溯。
4. 需要看整体设计时，先读 `方案设计.md` 的"设计总览"。

## 历史版本

`历史版本/` 下为已归档的迭代稿（方案设计/发票表设计 v1~v5 及反馈/建议稿），不作为现行依据。
