# 04-项目知识库

本目录沉淀真实项目的代码结构、模块地图、业务链路、外部接口经验和开发约定。

项目知识库应优先记录“真实代码位置”和“同类实现”，避免脱离代码的抽象说明。

## 建议沉淀内容

| 类型 | 示例 |
| --- | --- |
| 架构速览 | 网关、认证、业务模块、API 契约、前端工程 |
| 模块地图 | 交易、清分、结算、发票、商户、报表、外部接口 |
| 代码约定 | Controller、Service、Mapper、XML、前端页面写法 |
| 外部接口 | 支付、银行、省中心、税务、乐企等接入经验 |
| 高风险规则 | 扣款、退款、冲正、补扣、清分、结算、对账、发票 |

## 与真实代码仓库的关系

如果真实代码仓库已有 `docs` 目录，应优先引用真实仓库内文档。

本目录可记录跨需求复用的知识索引，但不要复制敏感信息。
