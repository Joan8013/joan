# 静态检查配置（Checkstyle + SpotBugs + 安全扫描）

给 extend_platform 后端引入静态检查门禁。当前仅有 Enforcer/JaCoCo/前端 ESLint，后端缺静态检查。
所有版本兼容 **Java 8**。**大型遗留库务必按 §4 分阶段落地，勿一上来卡门。**

## 1. 版本

```xml
<properties>
    <checkstyle.plugin.version>3.1.2</checkstyle.plugin.version>
    <checkstyle.version>8.45.1</checkstyle.version>
    <spotbugs.plugin.version>4.7.3.6</spotbugs.plugin.version>
    <findsecbugs.version>1.12.0</findsecbugs.version>
    <!-- 配置文件位置（放到根目录 config/ 或独立 build-tools 模块） -->
    <checkstyle.config.file>${maven.multiModuleProjectDirectory}/config/checkstyle/checkstyle.xml</checkstyle.config.file>
    <checkstyle.suppressions.file>${maven.multiModuleProjectDirectory}/config/checkstyle/checkstyle-suppressions.xml</checkstyle.suppressions.file>
    <spotbugs.exclude.file>${maven.multiModuleProjectDirectory}/config/spotbugs/spotbugs-exclude.xml</spotbugs.exclude.file>
</properties>
```

把本目录的 `checkstyle.xml`、`checkstyle-suppressions.xml` 放到 `config/checkstyle/`；
`spotbugs-exclude.xml` 放到 `config/spotbugs/`。

## 2. 根 pom `<build><pluginManagement>`

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-checkstyle-plugin</artifactId>
    <version>${checkstyle.plugin.version}</version>
    <dependencies>
        <dependency>
            <groupId>com.puppycrawl.tools</groupId>
            <artifactId>checkstyle</artifactId>
            <version>${checkstyle.version}</version>
        </dependency>
    </dependencies>
    <configuration>
        <configLocation>${checkstyle.config.file}</configLocation>
        <includeTestSourceDirectory>false</includeTestSourceDirectory>
        <consoleOutput>true</consoleOutput>
        <!-- 落地初期：false=只报告不失败；稳定后改 true 卡门 -->
        <failOnViolation>false</failOnViolation>
        <violationSeverity>warning</violationSeverity>
    </configuration>
</plugin>

<plugin>
    <groupId>com.github.spotbugs</groupId>
    <artifactId>spotbugs-maven-plugin</artifactId>
    <version>${spotbugs.plugin.version}</version>
    <configuration>
        <effort>Max</effort>
        <threshold>Medium</threshold>
        <excludeFilterFile>${spotbugs.exclude.file}</excludeFilterFile>
        <!-- 落地初期：false=只报告；稳定后改 true -->
        <failOnError>false</failOnError>
        <plugins>
            <plugin>
                <groupId>com.h3xstream.findsecbugs</groupId>
                <artifactId>findsecbugs-plugin</artifactId>
                <version>${findsecbugs.version}</version>
            </plugin>
        </plugins>
    </configuration>
</plugin>
```

## 3. `-Pquality-gate` Profile（在根 pom `<profiles>`）

平时不跑，显式开启才执行，避免拖慢日常构建：

```xml
<profile>
    <id>quality-gate</id>
    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-checkstyle-plugin</artifactId>
                <executions>
                    <execution>
                        <id>checkstyle-check</id>
                        <phase>verify</phase>
                        <goals><goal>check</goal></goals>
                    </execution>
                </executions>
            </plugin>
            <plugin>
                <groupId>com.github.spotbugs</groupId>
                <artifactId>spotbugs-maven-plugin</artifactId>
                <executions>
                    <execution>
                        <id>spotbugs-check</id>
                        <phase>verify</phase>
                        <goals><goal>check</goal></goals>
                    </execution>
                </executions>
            </plugin>
        </plugins>
    </build>
</profile>
```

## 4. 分阶段落地（遗留库关键，勿跳过）

1. **第一阶段（只报告）**：`failOnViolation/failOnError=false`。跑 `mvn -Pquality-gate verify`，看 target 下报告，摸清存量规模，不阻断。
2. **第二阶段（豁免存量）**：用 `checkstyle-suppressions.xml` / `spotbugs-exclude.xml` 把存量老域豁免；**只对新增/在改的类生效**。
3. **第三阶段（安全项先硬卡）**：把 find-sec-bugs 的 SQL 注入、硬编码密钥等安全类先设为必过（对齐编码约定安全红线）。
4. **第四阶段（全面卡门）**：存量逐步治理后，把 `failOnViolation/failOnError` 改 `true`，接入 `04-AI完成前质量门禁清单`。

> 建议配合 git diff 只检查变更文件（如用 `checkstyle:check` 前置筛选或 CI 增量），进一步降低遗留噪音。

## 5. 常用命令

```bash
mvn -Pquality-gate verify                     # 跑 Checkstyle + SpotBugs（含安全扫描）
mvn checkstyle:checkstyle                      # 仅生成 Checkstyle 报告(target/site)
mvn com.github.spotbugs:spotbugs-maven-plugin:gui   # 图形界面看 SpotBugs 结果
```

## 6. 接入检查清单

稳定卡门后，在 `02-资产层/03-检查清单库/04-AI完成前质量门禁清单.md` 增加：
