# 02-资产层

资产层沉淀可复用的 Prompt、模板、检查清单、项目知识、测试资产和 Superpowers 技能方法。

资产层服务于 HSC 需求工作台，帮助需求 Owner 和 AI 在不同阶段复用团队经验。

## 1. 当前结构

```text
02-资产层/
├── 01-Prompt库/
├── 02-模板库/
├── 03-检查清单库/
├── 04-项目知识库/
├── 05-测试资产库/
└── 06-Superpowers技能方法/
```

## 2. 目录说明

| 目录 | 作用 |
| --- | --- |
| `01-Prompt库` | 存放不同阶段可复用的 AI 协作 Prompt |
| `02-模板库` | 存放跨需求复用的通用模板 |
| `03-检查清单库` | 存放需求澄清、影响分析、编码、上线等检查清单 |
| `04-项目知识库` | 存放项目结构、模块地图、代码约定、外部接口经验 |
| `05-测试资产库` | 存放测试断言、测试场景、测试数据构造和回归场景 |
| `06-Superpowers技能方法` | 存放 Superpowers 的 AI 执行方法卡，强调 Process over Prompt |

## 3. 使用入口

日常需求执行优先读取：

```text
02-资产层/README.md
02-资产层/06-Superpowers技能方法/00-技能选择总入口.md
```

需要某阶段 Prompt 时，再读取：

```text
02-资产层/01-Prompt库/README.md
```

资产层是工具箱，不是流程层。当前需求事实以 `03-需求工作台/<REQ>/STATUS.md` 和阶段主文档为准。

## 5. 使用规则

1. Prompt 只生成当前阶段主文档草案，不默认新建 `v1/v2/v3`。
2. Superpowers 只强化执行纪律，不增加额外过程文档。
3. 检查清单用于防漏，阶段文档只记录检查结论，不复制整张清单。
4. AI 参与关键产物时必须附带自我评估。
5. 资产不能替代业务、架构、测试、上线的人工确认。
6. 不得把账号、密码、密钥、证书、生产敏感数据写入资产层。
7. 每个 A 类需求复盘后，应评估是否更新资产层。
