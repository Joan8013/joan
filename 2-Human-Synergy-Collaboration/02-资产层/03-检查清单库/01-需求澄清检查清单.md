# 需求澄清检查清单

## 1. 基础信息

- [ ] 需求来源明确。
- [ ] 产品经理或业务联系人明确。
- [ ] 期望上线时间明确。
- [ ] 需求 Owner 明确。
- [ ] 风险等级已初判。

## 2. 范围边界

- [ ] 本期做什么已明确。
- [ ] 本期不做什么已明确。
- [ ] 后续阶段或二期内容已标记。
- [ ] 未确认事项已记录。
- [ ] 阻塞项已标记。

## 3. 高风险业务口径

- [ ] 是否影响扣款金额。
- [ ] 是否影响交易状态。
- [ ] 是否涉及退款、冲正、补扣。
- [ ] 是否影响清分规则。
- [ ] 是否影响结算规则。
- [ ] 是否影响商户资金归属。
- [ ] 是否影响发票、税额、开票状态。
- [ ] 是否影响对账和报表口径。
- [ ] 是否涉及权限和数据范围。
- [ ] 是否涉及外部接口。
- [ ] 是否涉及定时任务和补偿。
- [ ] 是否涉及幂等和重复执行。
- [ ] 是否涉及历史数据或生产数据修复。
- [ ] 是否影响系统可用性或核心业务连续性。
- [ ] 是否影响关键日志、监控指标、链路追踪或告警规则。

## 4. 准出

- [ ] 产品已确认关键业务口径。
- [ ] 需求 Owner 已确认可以进入影响分析。
- [ ] A 类风险已提交技术项目负责人确认。
