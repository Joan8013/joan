# AI 完成前质量门禁清单

AI 辅助完成代码后，提交给人工 Review 前必须检查。

## 1. 需求一致性

- [ ] 实现未偏离需求澄清结论。
- [ ] 实现未自行新增业务规则。
- [ ] 实现未扩大需求范围。
- [ ] 未确认事项没有被代码默认假设。

## 2. 代码位置

- [ ] 代码放在正确模块。
- [ ] 未新增无关模块。
- [ ] 未把业务逻辑写进 Controller。
- [ ] 未把三方接口逻辑放错模块。

## 3. 安全质量

- [ ] 无硬编码敏感信息。
- [ ] 无 SQL 注入风险。
- [ ] 权限和数据范围正确。
- [ ] 日志未打印敏感信息。
- [ ] 金额计算未使用 double。
- [ ] 幂等和重复执行风险已处理或标记。

## 4. 测试验证

- [ ] 编译已执行或说明未执行原因。
- [ ] 单元测试/接口测试已执行或说明未执行原因。
- [ ] 适合 TDD 的任务已有红-绿-重构记录。
- [ ] 不适合 TDD 的任务已说明原因和替代验证方式。
- [ ] 主链路已验证。
- [ ] 异常链路已验证或标记待测。
- [ ] 权限和数据隔离已验证或标记待测。

## 5. AI 自我评估

- [ ] 已附带 AI 自我评估；缺失时交付材料不完整。
- [ ] 已说明本次结论基于哪些材料。
- [ ] 已区分事实和推断。
- [ ] 已列出不确定事项。
- [ ] 已列出需要人工确认的结论。
- [ ] 已标记是否涉及资金、权限、生产数据、外部接口。
- [ ] 高风险和不确定事项已进入待确认事项或风险台账。

## 6. 交付说明

- [ ] 已列出代码改动文件。
- [ ] 已列出验证命令和结果。
- [ ] 已列出未完成事项。
- [ ] 已列出风险和建议下一步。
