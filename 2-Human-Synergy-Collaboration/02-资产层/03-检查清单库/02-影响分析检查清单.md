# 影响分析检查清单

## 1. 前端影响

- [ ] 管理端是否影响。
- [ ] 商户端是否影响。
- [ ] 服务区端是否影响。
- [ ] 页面、路由、API JS 是否影响。
- [ ] 权限按钮和菜单是否影响。

## 2. 后端影响

- [ ] Controller 是否影响。
- [ ] Service / ServiceImpl 是否影响。
- [ ] Mapper / XML 是否影响。
- [ ] Domain / DTO / VO 是否影响。
- [ ] Feign API 是否影响。
- [ ] 定时任务是否影响。
- [ ] 配置项是否影响。

## 3. 数据库影响

- [ ] 是否新增表。
- [ ] 是否修改表结构。
- [ ] 是否新增索引或唯一约束。
- [ ] 是否涉及历史数据迁移。
- [ ] 是否涉及生产数据修复。
- [ ] 是否需要 SQL 脚本。

## 4. 业务风险

- [ ] 是否影响扣款。
- [ ] 是否影响退款、冲正、补扣。
- [ ] 是否影响清分。
- [ ] 是否影响结算。
- [ ] 是否影响发票。
- [ ] 是否影响对账。
- [ ] 是否影响报表。

## 5. 技术风险

- [ ] 是否存在重复执行风险。
- [ ] 是否需要幂等控制。
- [ ] 是否存在外部接口超时或失败补偿。
- [ ] 是否影响 QPS、吞吐量或核心链路响应时间。
- [ ] 是否影响超时、重试、熔断或限流策略。
- [ ] 是否影响系统启动或关键初始化流程。
- [ ] 是否影响关键日志、监控指标、链路追踪或告警规则。
- [ ] 是否存在 SQL 注入风险。
- [ ] 是否存在权限绕过风险。
- [ ] 是否存在敏感信息泄漏风险。

## 6. 准出

- [ ] 主要代码路径已明确。
- [ ] 同类实现已阅读。
- [ ] 风险和待确认事项已记录。
- [ ] 可以支撑方案设计。
