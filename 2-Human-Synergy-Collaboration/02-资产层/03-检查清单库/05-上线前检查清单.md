# 上线前检查清单

## 1. 版本和范围

- [ ] 上线需求范围明确。
- [ ] 镜像或构建物版本明确。
- [ ] 代码分支或提交明确。
- [ ] 上线服务清单明确。

## 2. 数据库

- [ ] SQL 脚本已确认。
- [ ] SQL 已在测试环境验证。
- [ ] 是否可回滚已确认。
- [ ] 数据修复脚本有备份和校验方案。

## 3. 配置

- [ ] 配置项清单明确。
- [ ] 外部接口地址明确。
- [ ] 开关项明确。
- [ ] 密钥、证书、密码未写入文档明文。

## 4. 验证

- [ ] 上线后验证步骤明确。
- [ ] 验证账号和数据准备明确。
- [ ] 关键接口或页面验证明确。
- [ ] 监控和日志观察点明确。

## 5. 回滚

- [ ] 回滚条件明确。
- [ ] 回滚步骤明确。
- [ ] 回滚负责人明确。
- [ ] 回滚后验证明确。

## 6. 审批

- [ ] 产品或业务方按需确认。
- [ ] 技术项目负责人确认。
- [ ] 上线负责人确认。
- [ ] A 类需求已完成必要专家确认。
