# brainstorming：需求澄清与方案探索

## 1. 适用场景

1. 原始需求模糊。
2. 业务口径不完整。
3. 方案有多种可能。
4. 需要识别风险和待确认事项。

## 2. 操作步骤

1. 复述当前理解。
2. 列出已知事实。
3. 列出不确定事项。
4. 提出澄清问题。
5. 给出 2-3 个候选方案或解释路径。
6. 标记需要产品、Owner、架构师或测试负责人确认的事项。
7. 附带 AI 自我评估。

## 3. 输出产物

1. 需求摘要。
2. 澄清问题清单。
3. 范围和非范围建议。
4. 方案对比。
5. 风险和待确认事项。

## 4. 禁止事项

1. 不替产品确认业务口径。
2. 不把候选方案写成最终方案。
3. 不自行补全金额、状态、清分、结算、发票、权限规则。
4. 不忽略可用性和可观测性风险。
