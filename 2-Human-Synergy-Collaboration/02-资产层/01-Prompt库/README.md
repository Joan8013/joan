# 01-Prompt库

本目录存放可复用的 AI 协作 Prompt。

使用原则：

1. Prompt 必须绑定具体阶段。
2. Prompt 输出的是草案、清单、建议或检查结果，不替代人工确认。
3. A 类需求使用 Prompt 后，必须由对应角色复核关键结论。
4. Prompt 中不得要求 AI 猜测业务口径、生产配置、密钥或上线决策。

## 使用要求

1. Prompt 输出写回当前阶段主文档。
2. 不默认生成多版本文档。
3. 已确认事项写入阶段主文档的确认/决策小节。
4. 待确认事项只保留当前阶段必须确认的问题。
