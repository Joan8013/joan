# 01-流程层

流程层回答：

```text
一条需求从进入到上线，必须怎么走。
```

流程层定义阶段、关口、准入准出和每个阶段的最小产物。

## 1. 职责

1. 定义需求交付主流程。
2. 定义每个阶段的输入和输出。
3. 定义阶段准入准出规则。
4. 定义 AI 在各阶段的参与方式。
5. 定义评审和上线前关口。

## 2. 输入

| 输入 | 来源 |
| --- | --- |
| 原始需求 | 业务、产品、运营、外部接口方 |
| 治理层规则 | 风险分级、人工兜底规则、角色职责 |
| 可复用资产 | 模板、Prompt、Skill、示例 |

## 3. 输出

| 输出 | 去向 |
| --- | --- |
| 阶段流程 | 指导需求工作台目录推进 |
| 准入准出 | 控制每个阶段是否可以进入下一步 |
| AI 参与规则 | 防止 AI 越权或跳步 |
| 评审关口 | 支撑开发前、联调前、上线前判断 |

## 4. 边界

流程层不保存某条需求的实际过程产物，也不保存模板正文。

流程层只定义“怎么走”。具体执行内容放需求工作台，可复用材料放资产层。

## 5. 建议文件

| 文件 | 说明 |
| --- | --- |
| `需求交付流程.md` | 从需求录入到复盘的完整流程 |
| `阶段准入准出规则.md` | 每个阶段进入和完成的判断条件（含四个快速确认硬门禁） |
| `AI参与流程说明.md` | AI 在每个阶段可以做什么 |
| `评审关口清单.md` | 开发前、联调前、上线前评审检查 |
| `人类快速确认指南.md` | 前三关（澄清/编码前/测试）人怎么快速审 |
| `验收快速指南.md` | 第四关（验收）人做什么、怎么 10~15 分钟完成 |
