# 需求交付流程

## 1. 最小闭环

```text
原始材料
-> 需求澄清
-> 影响分析
-> 方案设计
-> 任务拆分
-> 开发与联调
-> 测试与验收
-> 复盘沉淀
```

## 2. 阶段说明

| 阶段 | 目标 | 主要产物 |
| --- | --- | --- |
| 原始材料 | 保留原始输入 | 原始需求、接口文档、截图、会议记录、外部资料 |
| 需求澄清 | 明确范围、非范围和待确认项 | 澄清问题清单、业务口径 |
| 影响分析 | 找到模块、接口、数据、状态和风险影响 | 影响分析、风险清单 |
| 方案设计 | 明确实现思路和边界 | 设计说明、方案评审结论 |
| 任务拆分 | 形成可排期、可验证的任务包 | 任务清单、验收断言、任务级验证目标、TDD 适用性 |
| 开发与联调 | 按任务实现、执行 TDD 或替代验证、完成代码 Review 和联调闭环 | 开发联调记录、TDD 记录、代码改动清单、联调记录、问题闭环 |
| 测试与验收 | 执行测试、完成交付前门禁、形成验收结论 | 测试结果、完成前验证记录、缺陷与风险、验收结论 |
| 复盘沉淀 | 抽取可复用经验 | 复盘、模板/Prompt/Skill 改进建议 |

## 3. 阶段内活动归属

以下事项是阶段内活动，不再作为独立流程阶段或独立默认文档：

| 活动 | 归属阶段 | 说明 |
| --- | --- | --- |
| TDD 红-绿-重构 | 开发与联调 | 在 `开发联调记录.md` 按任务记录；不放到验收阶段才开始 |
| 测试点和验收断言设计 | 任务拆分 | 在 `任务拆分.md` 定义；执行结果进入 `测试验收.md` |
| 代码 Review | 开发与联调 | 作为开发过程闭环和风险控制活动记录 |
| 联调 | 开发与联调 | 开发期跨系统、前后端或三方接口联调记录在本阶段 |
| 完成前验证 | 测试与验收 | 作为宣称完成前的门禁，不替代开发期 TDD 和自测 |
