# 评审关口清单

## 1. 开发前评审

1. 需求范围和非范围是否明确。
2. A/B/C 风险等级是否明确。
3. 金额、状态、幂等、清分、结算、对账等口径是否有人工确认。
4. 影响模块和接口是否识别。
5. 开发任务是否可分工、可验收。
6. 验收断言、任务级验证目标和 TDD 适用性是否已定义。

## 2. 测试验收前评审

1. 环境和数据是否准备。
2. 外部参与方是否明确。
3. 主链路和异常链路是否都有用例。
4. 日志、状态、失败原因是否可追踪。
5. 回滚或人工处理方案是否明确。
6. 开发期 TDD 或替代验证是否已有记录。
7. 代码评审意见是否已关闭、升级或转后续项。

## 3. 上线前评审

1. P0 测试是否通过。
2. 高风险口径是否关闭。
3. 异常和补偿链路是否可处理。
4. 监控和排查入口是否准备。
5. 负责人是否确认 Go/No-Go。
6. 完成前验证门禁是否通过。
