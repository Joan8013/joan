# 团队角色与职责

## 1. 角色定义

| 角色 | 职责 |
| --- | --- |
| 需求负责人 | 确认业务范围、非范围、优先级和验收目标 |
| 架构负责人 | 确认系统边界、数据流、风险点和关键方案 |
| 开发负责人 | 拆分任务、实现代码、控制技术风险 |
| 测试负责人 | 设计测试场景、执行测试验收、识别漏测风险 |
| 运营负责人 | 确认上线后查询、处理、补偿和人工操作路径 |
| 财务/结算负责人 | 确认金额、清分、结算、划账、对账口径 |
| AI 助理 | 辅助整理、分析、起草、检查和沉淀，不做最终裁决 |

## 2. 责任原则

1. AI 可以提出建议，但不能替代负责人确认。
2. A 类风险必须有明确人工确认人。
3. 任何上线结论都必须有人承担最终责任。
4. 需求工作台中的状态文档应记录关键待确认项和责任人。
