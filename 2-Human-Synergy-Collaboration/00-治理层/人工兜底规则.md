# 人工兜底规则

## 1. 必须人工确认的口径

| 口径 | 典型内容 |
| --- | --- |
| 金额 | 金额来源、金额计算、尾差处理、退款金额 |
| 状态 | 状态迁移、失败补偿、重试后最终状态 |
| 幂等 | 幂等键、命中处理、并发控制 |
| 清分 | 分润参与方、分润比例、清分明细 |
| 结算 | 结算周期、结算对象、结算金额 |
| 划账 | 划账对象、划账金额、划账失败处理 |
| 对账 | 对账维度、差错处理、报表口径 |

## 2. 兜底要求

1. 必须有明确确认人。
2. 必须留下确认结论。
3. 必须能追溯到需求、方案或评审记录。
4. AI 生成的结论只能作为草案。

## 3. No-Go 条件

如果 A 类风险口径没有人工确认，不应进入核心代码实现或上线判断。
